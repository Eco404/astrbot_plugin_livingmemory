# WebUI 导览

LivingMemory 使用 AstrBot 官方插件 Pages，不需要启动独立管理服务。

入口：`插件 → LivingMemory → Pages → dashboard`

Dashboard 同时适配桌面和手机端。窄屏下使用左上角导航按钮打开侧边栏；表格、工具栏、维护功能和详情浮窗会按可用宽度重新排列。横屏窄视口会使用紧凑布局，避免主要操作被遮挡。

## 日常页面

| 页面 | 用途 |
| --- | --- |
| 知识图谱 | 查看 Timeline 派生的实体与关系；不是 Topic 召回的主入口 |
| Timeline 记忆 | 搜索、筛选、查看、编辑、暂存、导入导出 Timeline |
| Topic 记忆 | 查看只读 Topic、正式片段、事实、人物、情绪和来源；支持关键字与 Embedding 相关性搜索 |
| 补充人物资料 | 用稳定账号补充来源中含糊的人物信息，不能覆盖明确证据 |
| 系统概览 | 查看记忆、会话、模型、索引、维护和数据库状态 |

Timeline 与 Topic 页面右上角的“参数”只调整与当前记忆层直接相关的设置；完整设置集中在侧边栏 **设置** 页面，并按召回、生成、会话、生命周期、模型、性能等分类互通。

## 维护页面

侧边栏底部的 **维护** 聚合高风险或长耗时操作：

- Topic 记忆维护；
- Timeline 记忆维护；
- 会话审计与清理；
- 数据库健康检查和空间维护；
- 最近真实召回；
- 召回测试；
- 模型测试。

所有从 WebUI 启动的后台任务都应显示当前阶段、已处理数量和状态。失败任务保留错误说明，并允许用户清除记录。

## 详情交互

Topic、Timeline 和召回结果使用只读详情浮窗。Topic 来源中的 Timeline 可以继续打开完整内容；嵌套浮窗拥有独立滚动区域，关闭后返回原 Topic，不改变筛选和滚动位置。

Topic 拆分/合并在预览刷新后保留主 Topic 与片段分组选择。确认执行后，相关按钮会立即锁定直至操作结束，避免连续点击创建重复任务；其他长耗时操作遵循同一交互约束。

## 深色模式与语言

Dashboard 支持中文、English、Русский 和深色模式。文档站当前提供中文与 English；WebUI 的业务行为不因显示语言变化。
